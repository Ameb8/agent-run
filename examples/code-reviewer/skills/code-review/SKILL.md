# Code Review Best Practices

When reviewing code:
1. Prioritize bugs, security risks, concurrency errors, and data loss possibilities.
2. Verify that public interfaces and boundary conditions handle nil/null, empty inputs, and error paths properly.
3. Keep comments constructive, specific, and actionable. Provide line references and suggested fixes where appropriate.
